# RollScribe 掷骰记录工具｜V1.0 功能文档

> 
> 项目工程名：`roll-scribe`
> 小程序名称：RollScribe掷骰记录工具
> 定位：轻量TRPG/桌游骰子辅助小程序，**MVP版本，仅基础掷骰+掷骰人+历史记录，无高级骰语法、无优势劣势、无联机**
> 类目：工具 - 娱乐工具
> 目标用户：DND、COC等跑团玩家、桌游玩家

## 一、产品概述

RollScribe 掷骰记录工具是一款极简桌游掷骰辅助小程序。V1.0 核心目标：支持选择1颗或多颗六面骰子进行投掷，可录入投掷人昵称，自动保存每一次投骰记录，提供历史记录查看能力。主打轻量、稳定、上手零成本，满足线下跑团对局基础投骰与留痕需求。

## 二、版本说明

- 当前版本：V1.0（首发MVP）
- 迭代备注：本版本**不包含**：D4/D8/D10/D12/D20、骰语法解析、优势/劣势判定、记录删除、导出、分享、联机、存档等高级功能，后续版本按需迭代。
- 技术载体：微信小程序（React + Taro / 原生小程序，可自选）

## 三、用户角色

仅一种角色：小程序使用者（跑团玩家/主持人，本地使用，无需登录、无需注册账号）

> 
> ✅ 无需微信授权登录，降低使用门槛；记录存在本地缓存（Storage），清除缓存/卸载小程序会丢失历史。

## 四、功能清单 & 详细需求

### 4.1 首页 - 掷骰面板（核心页面）

页面布局分区：投掷人输入区、骰子数量选择区、投骰结果展示区、功能按钮、历史记录入口

| 模块 | 功能描述 | 交互规则 |
| --- | --- | --- |
| 投掷人输入框 | 输入本次掷骰玩家昵称，非必填 | 文本输入，上限20字符；为空时，记录内投掷人展示【匿名】 |
| 骰子数量选择 | 选择本次投掷几颗6面骰子，范围：1 ~ 10颗 | 两种交互任选其一：   1. 加减按钮（+ / -）调整数量   2. 数字输入框；最小1，最大10，超出范围自动钳位 |
| 【开始投掷】按钮 | 触发掷骰逻辑，生成随机点数 | 点击后有简短动画（骰子滚动动效，可选）；生成每一颗骰子独立点数 + 总和；结果实时展示 |
| 结果展示区 | 展示本次投骰详情 | 展示：投掷人、骰子数量、每颗骰子点数列表、总和、投掷时间 |
| 历史记录入口按钮 | 跳转历史记录页面 | 固定位置，随时可以点击查看全部记录 |

> 
> 掷骰随机规则：单颗骰子随机范围 `[1,6]`，均匀随机；前端随机，不依赖后端。

### 4.2 历史记录页面

用于查看所有本地保存的掷骰记录列表

- 列表按**时间倒序排列**：最新的记录在最顶部
- 单条记录卡片字段：
  1. 投掷人（匿名/昵称）
  2. 骰子数量（如：3D6）
  3. 每颗骰子的点数明细：`[2,5,1]`
  4. 总和
  5. 投掷时间（精确到分钟，例如：2026-11-02 22:30）
- V1.0限制：**不支持删除单条记录、不支持清空记录、不支持搜索筛选**
- 存储方案：微信小程序本地 `wx.setStorage` 持久化缓存
  - 上限：最多保存最近 100 条记录，超过后自动丢弃最早的旧记录，防止缓存溢出

### 4.3 页面通用能力

1. 导航返回：子页面（历史记录）支持左上角返回首页
2. 适配：兼容微信小程序不同尺寸手机，深色模式可选（可选加分项，非强制）
3. 无广告、无付费、无用户注册

## 五、非功能需求（NFR）

1. 性能：掷骰响应 < 200ms；页面打开速度流畅，无阻塞
2. 兼容性：支持微信基础库 2.20+，覆盖绝大多数手机微信
3. 数据安全：所有历史记录仅保存在用户本地，不上传到后端服务器；无采集用户信息
4. 稳定性：随机逻辑无偏，不会固定出点数；缓存读写异常时静默容错，不崩溃

## 六、UI/UX 简单规范（给前端）

1. 配色：简约工具风，主色低饱和蓝灰，白色背景
2. 骰子图标：6面骰子图形，和小程序头像视觉统一
3. 动效：轻量掷骰滚动动画，不花哨，不影响性能；动画可关闭（可选）
4. 文案克制：所有文字简洁，无游戏化、博彩类描述

## 七、业务约束 & 审核注意事项

1. 产品定位严格为**桌游辅助工具**，文案、页面不出现“游戏、赌博、对战、开奖”等敏感词汇
2. 功能与小程序简介保持一致：简介只描述当前V1.0已实现功能，不提前承诺后续功能
3. 类目选择：工具 → 娱乐工具，不要选择游戏类目

## 八、缺陷与待迭代清单（V1.0 不做，后续版本）

- 支持D4/D8/D10/D12/D20多面体骰子
- 记录删除 / 一键清空历史
